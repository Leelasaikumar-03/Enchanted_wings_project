# 🦋 Enchanted Wings: Marvels of Butterfly Species

A machine learning-based butterfly species classification system using **VGG16 transfer learning** and Convolutional Neural Networks (CNNs).  
This project aims to support **biodiversity research** and **citizen science** by enabling easy and accurate identification of butterfly species.

---

## 📌 Features
- Classifies multiple butterfly species from images.
- Uses **transfer learning** for high accuracy with less training data.
- Web application for easy image upload and prediction.
- User-friendly interface built with **HTML/CSS**.
- Data preprocessing and augmentation for better model generalization.

---

## 📂 Dataset
- **Source:** [Kaggle – Butterfly Image Classification Dataset](https://www.kaggle.com/datasets)  
- **Preprocessing:** Image resizing, normalization, and augmentation applied.

---

## 🛠 Technologies Used
- **Programming Language:** Python
- **Frameworks & Libraries:** TensorFlow, Keras, Flask, NumPy, Pandas, Matplotlib
- **Model Architecture:** VGG16 Transfer Learning + CNN
- **Frontend:** HTML, CSS
